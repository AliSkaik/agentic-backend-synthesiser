### PostgreSQL Schema

```sql
CREATE TABLE rooms (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    room_type VARCHAR(100),
    base_price NUMERIC(10, 2) NOT NULL,
    beds INTEGER NOT NULL,
    capacity INTEGER NOT NULL
);

CREATE TABLE reservations (
    id SERIAL PRIMARY KEY,
    room_id INTEGER REFERENCES rooms(id),
    check_in DATE NOT NULL,
    check_out DATE NOT NULL,
    FOREIGN KEY (room_id) REFERENCES rooms(id)
);
```

### Express Router

```javascript
import express from 'express';
import pool from '../db.js';

const router = express.Router();

// Find the names of all modern rooms with a base price below $160 and two beds.
router.get('/modern-rooms', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT name
            FROM rooms
            WHERE room_type = 'Modern' AND base_price < 160 AND beds = 2;
        `);
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: error.message });
    }
});

// Find all the rooms that have a price higher than $160 and can accommodate more than two people. Report room names and ids.
router.get('/expensive-rooms', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT id, name
            FROM rooms
            WHERE base_price > 160 AND capacity > 2;
        `);
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: error.message });
    }
});

// Find the most popular room in the hotel. The most popular room is the room that had seen the largest number of reservations.
router.get('/most-popular-room', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT r.id, r.name
            FROM rooms r
            JOIN (
                SELECT room_id, COUNT(*) as reservation_count
                FROM reservations
                GROUP BY room_id
            ) sub ON r.id = sub.room_id
            ORDER BY sub.reservation_count DESC
            LIMIT 1;
        `);
        res.json(result.rows[0]);
    } catch (error) {
        res.status(500).json({ error: error.message });
    }
});

export default router;
```

### Explanation

1. **Database Schema**:
   - The `rooms` table stores information about each room, including its name, type, base price, number of beds, and capacity.
   - The `reservations` table stores information about each reservation, linking to the rooms table.

2. **Express Router**:
   - The router provides three endpoints:
     - `/modern-rooms`: Returns the names of all modern rooms with a base price below $160 and two beds.
     - `/expensive-rooms`: Returns the room names and IDs of all rooms that cost more than $160 and can accommodate more than two people.
     - `/most-popular-room`: Returns the name and ID of the most popular room, which is determined by the number of reservations.

Each endpoint uses a `pool.query` to execute the corresponding SQL query and returns the results as JSON.
