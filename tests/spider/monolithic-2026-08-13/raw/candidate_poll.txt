### PostgreSQL Schema

First, let's design the database schema for the candidate poll system.

```sql
CREATE TABLE polls (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE candidates (
    id SERIAL PRIMARY KEY,
    poll_id INT REFERENCES polls(id),
    name VARCHAR(255) NOT NULL,
    support_rate NUMERIC(5, 2) CHECK (support_rate BETWEEN 0 AND 100)
);
```

### Express Router

Next, let's create an Express router to handle the REST endpoints for this schema.

```javascript
import express from 'express';
import pool from '../db.js';

const router = express.Router();

// Endpoint to get the total number of candidates
router.get('/candidates/count', async (req, res) => {
    try {
        const result = await pool.query('SELECT COUNT(*) FROM candidates');
        res.json({ count: result.rows[0].count });
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// Endpoint to get the poll resource with the most number of candidate information
router.get('/polls/most-candidates', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT p.id, p.name, COUNT(c.id) AS candidate_count
            FROM polls p
            JOIN candidates c ON p.id = c.poll_id
            GROUP BY p.id, p.name
            ORDER BY candidate_count DESC
            LIMIT 1
        `);
        res.json(result.rows[0]);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// Endpoint to get the top 3 highest support rates
router.get('/candidates/top-support-rates', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT c.id, c.name, c.support_rate
            FROM candidates c
            ORDER BY c.support_rate DESC
            LIMIT 3
        `);
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

export default router;
```

### Explanation

1. **Database Schema**:
   - The `polls` table stores information about each poll, including its name and creation timestamp.
   - The `candidates` table stores information about each candidate, including their associated poll ID, name, and support rate.

2. **Express Router**:
   - `/candidates/count`: Returns the total number of candidates in the database.
   - `/polls/most-candidates`: Returns the poll resource that has the most number of candidate information.
   - `/candidates/top-support-rates`: Returns the top 3 highest support rates among candidates.

This setup ensures that you can efficiently query the database for the required information using a single response.
