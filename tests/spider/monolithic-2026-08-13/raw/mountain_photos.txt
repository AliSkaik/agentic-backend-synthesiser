### PostgreSQL Schema

```sql
CREATE TABLE camera_lenses (
    id SERIAL PRIMARY KEY,
    brand VARCHAR(255) NOT NULL,
    name VARCHAR(255) NOT NULL,
    focal_length_mm DECIMAL(10, 2) NOT NULL,
    max_aperture DECIMAL(3, 2) NOT NULL
);

CREATE TABLE photos (
    id SERIAL PRIMARY KEY,
    mountain_id INT NOT NULL,
    color_scheme VARCHAR(255),
    name VARCHAR(255)
);

CREATE TABLE mountains (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    height_meters DECIMAL(10, 2) NOT NULL,
    prominence DECIMAL(10, 2) NOT NULL,
    country VARCHAR(255) NOT NULL
);
```

### Express Router

```javascript
import express from 'express';
import pool from '../db.js';

const router = express.Router();

// Endpoint to find how many camera lenses have a focal length longer than 15 mm
router.get('/camera-lenses/count', async (req, res) => {
    try {
        const result = await pool.query('SELECT COUNT(*) FROM camera_lenses WHERE focal_length_mm > 15');
        res.json({ count: result.rows[0].count });
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// Endpoint to find the brand and name for each camera lens, sorted by maximum aperture in descending order
router.get('/camera-lenses', async (req, res) => {
    try {
        const result = await pool.query('SELECT brand, name FROM camera_lenses ORDER BY max_aperture DESC');
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// Endpoint to list the id, color scheme, and name for all the photos
router.get('/photos', async (req, res) => {
    try {
        const result = await pool.query('SELECT id, color_scheme, name FROM photos');
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// Endpoint to find the maximum and average height of the mountains
router.get('/mountains/heights', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT 
                MAX(height_meters) AS max_height,
                AVG(height_meters) AS avg_height
            FROM mountains
        `);
        res.json(result.rows[0]);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// Endpoint to find the average prominence of the mountains in country 'Morocco'
router.get('/mountains/prominence', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT 
                AVG(prominence) AS avg_prominence
            FROM mountains
            WHERE country = 'Morocco'
        `);
        res.json(result.rows[0]);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

export default router;
```

### Explanation

1. **Database Schema**:
   - `camera_lenses`: Stores information about camera lenses, including brand, name, focal length, and maximum aperture.
   - `photos`: Stores information about photos, including the mountain it belongs to, color scheme, and name.
   - `mountains`: Stores information about mountains, including their height, prominence, and country.

2. **Express Router**:
   - `/camera-lenses/count`: Returns the count of camera lenses with a focal length longer than 15 mm.
   - `/camera-lenses`: Returns the brand and name of each camera lens sorted by maximum aperture in descending order.
   - `/photos`: Returns the id, color scheme, and name for all photos.
   - `/mountains/heights`: Returns the maximum and average height of all mountains.
   - `/mountains/prominence`: Returns the average prominence of mountains in Morocco.

Each endpoint uses `pool.query` to execute SQL queries against the PostgreSQL database. The results are then returned as JSON responses.
