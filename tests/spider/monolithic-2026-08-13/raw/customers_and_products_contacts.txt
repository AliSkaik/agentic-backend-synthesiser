### PostgreSQL Schema

```sql
CREATE TABLE customers (
    customer_id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    phone VARCHAR(20),
    address_id INT,
    FOREIGN KEY (address_id) REFERENCES addresses(address_id)
);

CREATE TABLE products (
    product_id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    price DECIMAL(10, 2) NOT NULL
);

CREATE TABLE orders (
    order_id SERIAL PRIMARY KEY,
    customer_id INT,
    product_id INT,
    quantity INT NOT NULL,
    FOREIGN KEY (customer_id) REFERENCES customers(customer_id),
    FOREIGN KEY (product_id) REFERENCES products(product_id)
);

CREATE TABLE addresses (
    address_id SERIAL PRIMARY KEY,
    street VARCHAR(100),
    city VARCHAR(50),
    state VARCHAR(50),
    country VARCHAR(50)
);
```

### Express Router

```javascript
import express from 'express';
import pool from '../db.js';

const router = express.Router();

// 1. How many addresses are there in the USA?
router.get('/addresses/usa', async (req, res) => {
    try {
        const result = await pool.query('SELECT COUNT(*) FROM addresses WHERE country = $1', ['USA']);
        res.json({ count: result.rows[0].count });
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 2. Show all distinct cities in the address record.
router.get('/addresses/cities', async (req, res) => {
    try {
        const result = await pool.query('SELECT DISTINCT city FROM addresses');
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 3. Show each state and the number of addresses in each state.
router.get('/addresses/states', async (req, res) => {
    try {
        const result = await pool.query('SELECT state, COUNT(*) AS count FROM addresses GROUP BY state');
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 4. Show names and phones of customers who do not have address information.
router.get('/customers/no-address', async (req, res) => {
    try {
        const result = await pool.query('SELECT name, phone FROM customers WHERE address_id IS NULL');
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 5. Show the name of the customer who has the most orders.
router.get('/customers/most-orders', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT c.name
            FROM customers c
            JOIN orders o ON c.customer_id = o.customer_id
            GROUP BY c.customer_id, c.name
            ORDER BY COUNT(o.order_id) DESC
            LIMIT 1
        `);
        res.json(result.rows[0]);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

export default router;
```

### Explanation

1. **Database Schema**:
   - `customers` table stores customer details including an optional address ID.
   - `products` table stores product details.
   - `orders` table stores order details linking customers and products.
   - `addresses` table stores address details.

2. **Express Router**:
   - Each endpoint queries the database using a prepared statement to avoid SQL injection.
   - The results are returned as JSON responses.

This setup ensures that the backend can handle the required queries efficiently and securely.
