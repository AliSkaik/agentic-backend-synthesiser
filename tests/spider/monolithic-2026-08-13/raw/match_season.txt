### PostgreSQL Schema

```sql
CREATE TABLE countries (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL UNIQUE,
    capital VARCHAR(255) NOT NULL,
    official_language VARCHAR(255)
);
```

### Express Router (ES Module)

```javascript
import express from 'express';
import { pool } from '../db.js';

const router = express.Router();

// 1. Count the number of countries
router.get('/count-countries', async (req, res) => {
    try {
        const result = await pool.query('SELECT COUNT(*) FROM countries');
        res.json({ count: result.rows[0].count });
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 2. Show the country name and capital of all countries
router.get('/all-countries', async (req, res) => {
    try {
        const result = await pool.query('SELECT name, capital FROM countries');
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 3. Show all official native languages that contain the word "English"
router.get('/english-languages', async (req, res) => {
    try {
        const result = await pool.query('SELECT DISTINCT official_language FROM countries WHERE official_language LIKE %$1%', ['%English%']);
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

export default router;
```

### Explanation

1. **Database Schema**:
   - The `countries` table has columns for `id`, `name`, `capital`, and `official_language`.

2. **Express Router**:
   - Three endpoints are defined:
     1. `/count-countries`: Returns the total number of countries.
     2. `/all-countries`: Returns a list of all countries with their names and capitals.
     3. `/english-languages`: Returns a list of distinct official native languages that contain the word "English".

Each endpoint uses `pool.query` to execute SQL queries against the PostgreSQL database, handling errors appropriately and returning the results in JSON format.
