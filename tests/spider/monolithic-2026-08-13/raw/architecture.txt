### PostgreSQL Schema

```sql
CREATE TABLE architects (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    nationality VARCHAR(50),
    gender CHAR(1)
);

CREATE TABLE bridges (
    id SERIAL PRIMARY KEY,
    architect_id INT REFERENCES architects(id),
    length_meters DECIMAL(10, 2) NOT NULL
);

CREATE TABLE mills (
    id SERIAL PRIMARY KEY,
    architect_id INT REFERENCES architects(id),
    name VARCHAR(100) NOT NULL,
    year_of_construction INT,
    type VARCHAR(50)
);
```

### Express Router

```javascript
import express from 'express';
import pool from '../db.js';

const router = express.Router();

// 1. How many architects are female?
router.get('/architects/female-count', async (req, res) => {
    try {
        const result = await pool.query('SELECT COUNT(*) FROM architects WHERE gender = \'F\'');
        res.json({ count: result.rows[0].count });
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 2. List the name, nationality and id of all male architects ordered by their names lexicographically.
router.get('/architects/male', async (req, res) => {
    try {
        const result = await pool.query('SELECT name, nationality, id FROM architects WHERE gender = \'M\' ORDER BY name');
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 3. What is the maximum length in meters for the bridges and what are the architects' names?
router.get('/bridges/max-length', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT MAX(length_meters), a.name
            FROM bridges b
            JOIN architects a ON b.architect_id = a.id
            GROUP BY a.name
        `);
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 4. What is the average length in feet of the bridges?
router.get('/bridges/average-length-feet', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT AVG(length_meters * 3.28084) AS avg_length_feet
            FROM bridges
        `);
        res.json({ averageLengthFeet: result.rows[0].avg_length_feet });
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 5. What are the names and year of construction for the mills of 'Grondzeiler' type?
router.get('/mills/grondzeiler', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT m.name, m.year_of_construction
            FROM mills m
            WHERE m.type = 'Grondzeiler'
        `);
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

export default router;
```

### Explanation

1. **Architects Table**: Stores information about architects, including their gender.
2. **Bridges Table**: Stores information about bridges, linked to an architect via `architect_id`.
3. **Mills Table**: Stores information about mills, linked to an architect via `architect_id`.

### Express Router Endpoints

- `/architects/female-count`: Returns the count of female architects.
- `/architects/male`: Returns a list of male architects ordered by name.
- `/bridges/max-length`: Returns the maximum length in meters for each architect's bridges and their names.
- `/bridges/average-length-feet`: Returns the average length in feet of all bridges.
- `/mills/grondzeiler`: Returns the names and year of construction for mills of type 'Grondzeiler'.

Each endpoint uses `pool.query` to execute SQL queries against the PostgreSQL database.
