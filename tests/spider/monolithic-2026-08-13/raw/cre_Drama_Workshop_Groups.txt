### PostgreSQL Schema

Here is the SQL to create the necessary tables for managing Drama Workshop Groups:

```sql
CREATE TABLE drama_workshop_groups (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    description TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE bookings (
    id SERIAL PRIMARY KEY,
    group_id INT REFERENCES drama_workshop_groups(id),
    order_date DATE NOT NULL,
    planned_delivery_date DATE,
    actual_delivery_date DATE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (group_id) REFERENCES drama_workshop_groups(id)
);
```

### Express Router

Here is the Express router as one ES module implementing REST endpoints for the schema:

```javascript
import express from 'express';
import pool from '../db.js';

const router = express.Router();

// Get all drama workshop groups
router.get('/groups', async (req, res) => {
    try {
        const result = await pool.query('SELECT * FROM drama_workshop_groups');
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// Get all bookings
router.get('/bookings', async (req, res) => {
    try {
        const result = await pool.query('SELECT * FROM bookings');
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// Get the total number of bookings
router.get('/bookings/count', async (req, res) => {
    try {
        const result = await pool.query('SELECT COUNT(*) FROM bookings');
        res.json({ count: result.rows[0].count });
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// Get the order dates of all bookings
router.get('/bookings/order-dates', async (req, res) => {
    try {
        const result = await pool.query('SELECT order_date FROM bookings');
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// Get the planned and actual delivery dates of all bookings
router.get('/bookings/delivery-dates', async (req, res) => {
    try {
        const result = await pool.query('SELECT planned_delivery_date, actual_delivery_date FROM bookings');
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

export default router;
```

### Explanation

1. **Database Schema**:
   - `drama_workshop_groups`: Stores information about drama workshop groups.
   - `bookings`: Stores booking details, including the group it belongs to and delivery dates.

2. **Express Router**:
   - `/groups`: Returns all drama workshop groups.
   - `/bookings`: Returns all bookings.
   - `/bookings/count`: Returns the total number of bookings.
   - `/bookings/order-dates`: Returns the order dates of all bookings.
   - `/bookings/delivery-dates`: Returns the planned and actual delivery dates of all bookings.

This setup ensures that you can manage drama workshop groups and their bookings efficiently using PostgreSQL and Express.
