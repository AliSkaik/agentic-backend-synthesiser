### PostgreSQL Schema

Here is the PostgreSQL schema for the Cre Theme Park system:

```sql
CREATE TABLE hotels (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    location VARCHAR(255) NOT NULL,
    price DECIMAL(10, 2) NOT NULL
);
```

### Express Router

Here is an Express router that implements REST endpoints for the schema:

```javascript
import express from 'express';
import pool from '../db.js';

const router = express.Router();

// Endpoint to get the total number of available hotels
router.get('/total-hotels', async (req, res) => {
    try {
        const result = await pool.query('SELECT COUNT(*) FROM hotels');
        res.json({ totalHotels: result.rows[0].count });
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// Endpoint to get the price ranges of all hotels
router.get('/price-ranges', async (req, res) => {
    try {
        const result = await pool.query('SELECT MIN(price), MAX(price) FROM hotels');
        const { min, max } = result.rows[0];
        res.json({ minPrice: min, maxPrice: max });
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// Endpoint to get all distinct location names
router.get('/distinct-locations', async (req, res) => {
    try {
        const result = await pool.query('SELECT DISTINCT location FROM hotels');
        const locations = result.rows.map(row => row.location);
        res.json({ locations });
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

export default router;
```

### Explanation

1. **Database Schema (`hotels` table)**:
   - `id`: A unique identifier for each hotel.
   - `name`: The name of the hotel.
   - `location`: The location of the hotel.
   - `price`: The price of the hotel.

2. **Express Router**:
   - `/total-hotels`: Returns the total number of available hotels.
   - `/price-ranges`: Returns the minimum and maximum prices of all hotels.
   - `/distinct-locations`: Returns a list of distinct location names.

Each endpoint uses `pool.query` to execute SQL queries against the PostgreSQL database. The results are then formatted and returned as JSON responses.
