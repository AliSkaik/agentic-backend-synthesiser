### PostgreSQL Schema

```sql
CREATE TABLE customers (
    customer_id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL
);

CREATE TABLE products (
    product_id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    price NUMERIC(10, 2) NOT NULL
);

CREATE TABLE orders (
    order_id SERIAL PRIMARY KEY,
    customer_id INT REFERENCES customers(customer_id),
    product_id INT REFERENCES products(product_id),
    status VARCHAR(50) NOT NULL,
    payment_method VARCHAR(50) NOT NULL,
    truck_license_number VARCHAR(50)
);

CREATE TABLE deliveries (
    delivery_id SERIAL PRIMARY KEY,
    order_id INT REFERENCES orders(order_id),
    delivery_date TIMESTAMP NOT NULL
);
```

### Express Router

```javascript
import express from 'express';
import pool from '../db.js';

const router = express.Router();

// Endpoint to find the ids of orders whose status is 'Success'
router.get('/orders/success', async (req, res) => {
    try {
        const result = await pool.query('SELECT order_id FROM orders WHERE status = $1', ['Success']);
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// Endpoint to find the name and price of the product that has been ordered the greatest number of times
router.get('/products/most-ordered', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT p.product_id, p.name, p.price, COUNT(o.order_id) AS order_count
            FROM orders o
            JOIN products p ON o.product_id = p.product_id
            GROUP BY p.product_id, p.name, p.price
            ORDER BY order_count DESC
            LIMIT 1
        `);
        res.json(result.rows[0]);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// Endpoint to find the number of customers in total
router.get('/customers/count', async (req, res) => {
    try {
        const result = await pool.query('SELECT COUNT(customer_id) AS customer_count FROM customers');
        res.json(result.rows[0]);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// Endpoint to find the number of different payment methods
router.get('/payment-methods/count', async (req, res) => {
    try {
        const result = await pool.query('SELECT COUNT(DISTINCT payment_method) AS payment_method_count FROM orders');
        res.json(result.rows[0]);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// Endpoint to show the details of all trucks in the order of their license number
router.get('/trucks', async (req, res) => {
    try {
        const result = await pool.query('SELECT DISTINCT truck_license_number FROM orders ORDER BY truck_license_number');
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

export default router;
```

### Explanation

1. **Database Schema**:
   - `customers`: Stores customer details.
   - `products`: Stores product details.
   - `orders`: Stores order details, including the status and payment method.
   - `deliveries`: Stores delivery details.

2. **Express Router**:
   - `/orders/success`: Returns the IDs of orders with a status of 'Success'.
   - `/products/most-ordered`: Returns the product that has been ordered the most times along with its name, price, and order count.
   - `/customers/count`: Returns the total number of customers.
   - `/payment-methods/count`: Returns the number of different payment methods used in orders.
   - `/trucks`: Returns a list of unique truck license numbers, sorted by their license number.

Each endpoint uses `pool.query` to execute SQL queries against the PostgreSQL database. The results are then returned as JSON responses.
