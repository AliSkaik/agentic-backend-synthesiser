### PostgreSQL Schema

```sql
CREATE TABLE cities (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    country VARCHAR(255),
    year INT
);

CREATE TABLE events (
    id SERIAL PRIMARY KEY,
    city_id INT REFERENCES cities(id),
    event_name VARCHAR(255),
    date DATE
);
```

### Express Router

```javascript
import express from 'express';
import pool from '../db.js';

const router = express.Router();

// 1. What is the id of the city that hosted events in the most recent year?
router.get('/most-recent-city-id', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT city_id
            FROM events
            WHERE date >= DATE_TRUNC('year', CURRENT_DATE)
            ORDER BY date DESC
            LIMIT 1;
        `);
        res.json({ cityId: result.rows[0].city_id });
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 2. Find the city that hosted some events in the most recent year.
router.get('/most-recent-city', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT c.id, c.name
            FROM cities c
            JOIN events e ON c.id = e.city_id
            WHERE e.date >= DATE_TRUNC('year', CURRENT_DATE)
            ORDER BY e.date DESC
            LIMIT 1;
        `);
        res.json({ cityId: result.rows[0].id, cityName: result.rows[0].name });
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 3. Find the match ids of the cities that hosted competition "1994 FIFA World Cup qualification".
router.get('/match-ids-for-qualification', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT e.id
            FROM events e
            WHERE e.event_name = '1994 FIFA World Cup qualification';
        `);
        res.json({ matchIds: result.rows.map(row => row.id) });
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 4. Find the match id of the competition called "1994 FIFA World Cup qualification".
router.get('/match-id-for-qualification', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT id
            FROM events
            WHERE event_name = '1994 FIFA World Cup qualification';
        `);
        res.json({ matchId: result.rows[0].id });
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 5. Find the cities which were once a host city after 2010.
router.get('/cities-after-2010', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT id, name
            FROM cities
            WHERE year > 2010;
        `);
        res.json({ cities: result.rows });
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

export default router;
```

### Explanation

1. **Schema**:
   - `cities` table stores information about cities, including their ID, name, country, and year.
   - `events` table stores information about events, including their ID, city ID (foreign key referencing the `cities` table), event name, and date.

2. **Endpoints**:
   - `/most-recent-city-id`: Returns the ID of the city that hosted events in the most recent year.
   - `/most-recent-city`: Returns both the ID and name of the city that hosted events in the most recent year.
   - `/match-ids-for-qualification`: Returns the IDs of all matches that were part of the "1994 FIFA World Cup qualification" event.
   - `/match-id-for-qualification`: Returns the ID of the match for the "1994 FIFA World Cup qualification" event.
   - `/cities-after-2010`: Returns a list of cities that hosted events after the year 2010.

Each endpoint uses `pool.query` to execute SQL queries against the PostgreSQL database. The results are then returned as JSON responses.
