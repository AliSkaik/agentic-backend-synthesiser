### PostgreSQL Schema

```sql
CREATE TABLE farms (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    location VARCHAR(255),
    total_horses INT DEFAULT 0
);

CREATE TABLE horses (
    id SERIAL PRIMARY KEY,
    farm_id INT REFERENCES farms(id),
    name VARCHAR(255) NOT NULL,
    age INT
);

CREATE TABLE competitions (
    id SERIAL PRIMARY KEY,
    host VARCHAR(255) NOT NULL,
    theme VARCHAR(255)
);
```

### Express Router

```javascript
import express from 'express';
import pool from '../db.js';

const router = express.Router();

// 1. How many farms are there?
router.get('/farms/count', async (req, res) => {
    try {
        const result = await pool.query('SELECT COUNT(*) FROM farms');
        res.json({ count: result.rows[0].count });
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 2. List the total number of horses on farms in ascending order.
router.get('/farms/horses', async (req, res) => {
    try {
        const result = await pool.query('SELECT farm_id, SUM(total_horses) AS total_horses FROM farms GROUP BY farm_id ORDER BY total_horses ASC');
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 3. What is the total horses record for each farm, sorted ascending?
router.get('/farms/horses/total', async (req, res) => {
    try {
        const result = await pool.query('SELECT id, name, total_horses FROM farms ORDER BY total_horses ASC');
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

// 4. What are the hosts of competitions whose theme is not "Aliens"?
router.get('/competitions/hosts', async (req, res) => {
    try {
        const result = await pool.query('SELECT host FROM competitions WHERE theme != \'Aliens\'');
        res.json(result.rows);
    } catch (error) {
        res.status(500).json({ error: 'Internal Server Error' });
    }
});

export default router;
```

### Explanation

1. **Farms Table**: Stores information about each farm, including the total number of horses.
2. **Horses Table**: Stores information about each horse, linked to a specific farm via `farm_id`.
3. **Competitions Table**: Stores information about competitions, including the host and theme.

The Express router provides four endpoints:
- `/farms/count`: Returns the total number of farms.
- `/farms/horses`: Returns the total number of horses for each farm in ascending order.
- `/farms/horses/total`: Returns a list of all farms with their total horse count, sorted by the total horse count.
- `/competitions/hosts`: Returns the hosts of competitions whose theme is not "Aliens".
